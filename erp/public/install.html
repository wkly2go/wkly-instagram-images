휴대폰 홈 화면에 인트라넷 앱 설치

앱 스토어 없이 설치합니다. 설치하면 아이콘으로 바로 열리고, 주소창 없이 전체 화면으로 쓰며, 채팅 · 결재 알림을 받을 수 있습니다.

1. 휴대폰 카메라로 QR 을 찍으세요

wkly-erp.pages.dev

QR 이 열리면 회사 계정으로 로그인한 뒤, 아래 순서대로 홈 화면에 추가합니다.

안드로이드 (갤럭시)

앱 파일로 설치 (추천)

안드로이드 앱 내려받기 (APK)
  1. 휴대폰에서 위 버튼을 눌러 wkly-erp.apk 를 받습니다
  2. 받은 파일을 열고 설치 (처음이면 '출처를 알 수 없는 앱' 허용 › 다시 설치)
  3. 홈 화면의 WKLY ERP 아이콘으로 엽니다

또는 Chrome 에서

  1. Chrome 으로 인트라넷을 엽니다
  2. 오른쪽 위 ⋮ 메뉴 › 앱 설치 (또는 홈 화면에 추가)
  3. 설치 를 누르면 홈 화면에 WKLY 아이콘이 생깁니다

삼성 인터넷: 아래 메뉴 › 현재 페이지 추가 › 홈 화면

아이폰 · 아이패드

Safari 에서

  1. Safari 로 인트라넷을 엽니다 (카카오톡 · 네이버 앱 안에서는 안 됩니다)
  2. 아래 가운데 공유 버튼 (네모에 위쪽 화살표)
  3. 홈 화면에 추가 › 오른쪽 위 추가

알림을 받으려면 홈 화면 아이콘으로 연 뒤 알림을 허용해 주세요 (iOS 16.4 이상).

설치한 뒤

  1. 홈 화면의 WKLY ERP 아이콘으로 엽니다
  2. 아이콘을 길게 누르면 빠른 기록 · 승인 · 채팅 으로 바로 갈 수 있습니다 (안드로이드)
  3. 새 기능은 따로 업데이트할 필요 없이 열 때마다 자동으로 반영됩니다
