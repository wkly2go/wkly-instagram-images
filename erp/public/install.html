휴대폰 홈 화면에 인트라넷 앱 설치

앱 스토어 없이 설치합니다. 설치하면 아이콘으로 바로 열리고, 주소창 없이 전체 화면으로 쓰며, 채팅 · 결재 알림을 받을 수 있습니다.

1. 휴대폰 카메라로 QR 을 찍으세요

wkly-erp.pages.dev

QR 이 열리면 회사 계정으로 로그인한 뒤, 아래 순서대로 홈 화면에 추가합니다.

안드로이드 (갤럭시)

웹 앱으로 설치 (추천)

인트라넷 화면을 그대로 홈 화면 앱으로 씁니다. 새 기능은 앱을 다시 받지 않아도 바로 반영됩니다.

  1. Chrome 으로 wkly-erp.pages.dev 를 엽니다
  2. 오른쪽 위 ⋮ 메뉴 › 홈 화면에 추가 (또는 앱 설치)
  3. 설치 를 누르면 홈 화면에 WKLY 아이콘이 생깁니다

예전 앱 파일(APK)을 쓰려면: wkly-erp.apk

삼성 인터넷: 아래 ≡ 메뉴 › 현재 페이지 추가 › 홈 화면

아이폰 · 아이패드

앱 설치 파일로 (추천)

아이폰 앱 설치 파일 받기
  1. Safari 에서 위 버튼 › 허용 (프로파일이 다운로드됨)
  2. 설정 앱 맨 위 프로파일이 다운로드됨 을 누릅니다
    안 보이면 설정 › 일반 › VPN 및 기기 관리
  3. 오른쪽 위 설치 › 암호 입력 › 설치
  4. 홈 화면에 WKLY ERP 아이콘이 생깁니다

'확인되지 않음' 표시는 회사가 직접 만든 설치 파일이라 나오는 것으로, 앱 아이콘 하나만 만들고 다른 설정은 바꾸지 않습니다. 지울 때는 아이콘을 길게 눌러 삭제하거나 같은 메뉴에서 프로파일 제거.

또는 Safari 에서

  1. Safari 로 인트라넷을 엽니다 (카카오톡 · 네이버 앱 안에서는 안 됩니다)
  2. 아래 가운데 공유 버튼 (네모에 위쪽 화살표)
  3. 홈 화면에 추가 › 오른쪽 위 추가

채팅 · 결재 알림은 이 방법(Safari › 홈 화면에 추가)으로 설치한 아이콘에서 가장 확실하게 옵니다. 앱으로 연 뒤 알림을 허용해 주세요 (iOS 16.4 이상).

설치한 뒤

  1. 홈 화면의 WKLY ERP 아이콘으로 엽니다
  2. 아이콘을 길게 누르면 빠른 기록 · 승인 · 채팅 으로 바로 갈 수 있습니다 (안드로이드)
  3. 새 기능은 따로 업데이트할 필요 없이 열 때마다 자동으로 반영됩니다
