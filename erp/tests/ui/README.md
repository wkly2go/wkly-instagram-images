# 영업·연락처 React DOM 통합 검사

```sh
npm ci
npm run test:ui
```

`growth-dom.test.mjs`는 Vite가 불러온 실제 React 컴포넌트를 jsdom에 렌더하고 사용자 입력·클릭·선택 이벤트를 실행합니다. Supabase 환경값은 빈 값으로 강제하며 기존 체험용 API와 합성 연락처만 사용합니다. 네트워크 요청은 거부합니다. 운영 계정, 실제 메일, 유료 AI, DB, Storage는 사용하지 않습니다.

검사 범위:

- 관리자·팀원의 영업 신규 저장, 주소 매개변수 유지, 닫기 및 미저장 확인.
- 연락처 부분 실패 후 성공 후보 제거, 실패 후보 ID·초안 유지, 같은 자료 미리보기, 남은 후보만 재시도.
- 다른 이동 보호가 저장 후 이동을 막을 때 같은 ID·최신 revision으로 재저장.
- 저장 중 이동·Escape 차단, 응답 유실 후 저장 내용 재확인.
- 다른 담당자 자료의 읽기 전용 표시 및 동시 수정 충돌 시 초안 보존.
- 회의록 요청 접수 결과가 불명확할 때 새 업로드를 숨기고 기존 기록 ID만 다시 조회하여 완료 결과를 적용. 합성 `.txt`를 파일 입력 이벤트로 올리며 마이크·화면 공유는 차단합니다.
- 나라장터 합성 조회 결과에서 등록 초안 채우기, 명시적 저장 전 쓰기 없음, 미저장 보호, 조회 중 닫기·이동 차단, 조건 변경 시 이전 후보 제거, 다른 초안의 이동 보호 유지.
- 나라장터 다음 페이지 조회 실패 시 이전 결과 보존, 동일 조건·실패 페이지의 명시적 재시도, 조건 변경 시 이전 실패 페이지 재시도 제거.

이 검사는 실제 Chromium 실행, 화면 배치·반응형·키보드 접근성 전체, 운영 관리자·팀원 계정, Supabase RLS 또는 외부 연동 검증을 대신하지 않습니다. 해당 항목은 별도로 확인해야 합니다.
