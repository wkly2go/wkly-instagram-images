## 설정 및 예약

- 회의록의 `ANTHROPIC_API_KEY`와 기본 Supabase 환경값은 이름의 존재만 확인했습니다. 값은 읽거나 기록하지 않았습니다.
- `DATA_GO_KR_SERVICE_KEY`는 Secrets 검색에서 발견되지 않았습니다. 나라장터 함수 배포는 완료됐지만 **공공데이터포털 활용 승인과 서버 키 등록, 실제 응답 확인은 남아 있습니다.** 키를 채팅·프론트엔드·소스에 넣지 않습니다.
- 읽기 전용 SQL로 `wkly_gmail_sync`의 10분 예약(`*/10 * * * *`)과 `wkly_housekeeping`의 일일 예약(`0 18 * * *`)이 활성 상태임을 확인했습니다. 각 예약의 최신 스케줄러 기록은 succeeded였습니다. 스케줄러 성공은 외부 HTTP 요청 완료·메일 전체 수집·연락처 생성 성공을 보증하지 않습니다.
- 기존 Gmail 예약을 새로 만들거나 직접 실행하지 않았습니다. 활성 예약은 배포된 새 코드를 사용할 수 있으며 기존 첨부 Drive 저장 동작도 유지됩니다.
