# AI 팀·비용 메뉴 통합 — 2026-11-13

기준 main `8c03eb54398ca592b53cf579bed06747ab4643b1`의 기존 영업·광고·서버 변경을 보존했다.

## 사용 방법

- PC 왼쪽 메뉴 / 휴대폰 더보기의 **AI 팀·비용**(`/agents`)에서 관리한다.
- 모든 팀원: **팀원·지시·예약**, **사용·비용**. 비용 기록은 기존 서버 정책대로 일반 팀원에게 본인 기록만 표시한다.
- 관리자: 위 두 메뉴와 **예약 작업 점검**, **조직도·관리자**, **일일 보고**, **관리 요청**, **AI 처리 기록**. 기존 권한과 모델·기간 한도·정산 기능을 유지한다.
- 예전 `/ai-usage`는 `/agents?tab=usage`로 연결한다. 날짜·선택 팀원·기타 매개변수는 유지한다. 보고서 날짜가 있는 주소에서 팀원 탭으로 돌아가도 다시 보고서로 열리지 않는다.
- 전체 검색에서 AI팀 / AI 사용 / 비용 / 예산 / API로 통합 메뉴를 찾는다. 중복 메뉴는 제거했다.
- 지시·팀원 설정·예약 초안·비용 설정·정산 입력·AI 요청을 수정한 뒤 메뉴를 바꾸면 확인한다. 저장·API 실행 중 이동은 차단한다. 이 보호는 새로고침 뒤 초안 영구 보존을 뜻하지 않는다.

## 비용 집계 범위

이 변경은 메뉴 통합이다. 영업·콘텐츠 등 업무 도구의 기존 집계를 그대로 사용한다. AI 팀원 채팅·예약 작업·회의록·다른 키의 비용, 구독료, 크레딧 잔액을 새로 합산하거나 조회하지 않는다. 전체 API 비용은 Console에서 별도로 확인한다. 메뉴 이동만으로 AI 실행·한도 변경은 발생하지 않는다. 서버 함수·DB·RLS 정책 변경 없음.

## 검증

- 기능·로컬 DB 등 전체 회귀 **331/331**, 실제 React DOM **40/40**, 합계 **371/371** 통과.
- 신규 DOM 회귀 9개: 일반 팀원 접근/조회만 수행, 관리자 메뉴·날짜 보존, 이전 주소, 권한 없는/알 수 없는 탭, AI 요청 초안·실행 중 이동 차단, 팀원 지시 보존, 검색 통합, 비용 설정 초안·저장 중 보호, 새 팀원 저장 뒤 선택.
