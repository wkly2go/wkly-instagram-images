## 가능 여부 검토

### 1. 슬랙 · 카카오톡 연결 — 가능 (카카오톡은 방식 제한)
- **슬랙**: 공식 API 로 채널 대화 · 파일을 모두 가져올 수 있음 (무료). 이미 만들었고 운영 적용만 남음.
  - 더할 것: ~~매시간 자동 가져오기~~ (1분마다로 완료) · (선택) 인트라넷 결재 · 지시 알림을 슬랙 채널로 보내기
- **카카오톡**: 개인 · 단체 카톡방 대화를 프로그램이 읽어 오는 공식 API 는 **없음** (카카오 정책상 불가).
  - 가능한 방법 ①: 카톡 **'대화 내용 내보내기'**(텍스트 · 사진 묶음)를 인트라넷에 올리면 프로젝트별로 정리 · 사진 · 파일은 드라이브에 저장 → **무료 · 확실**
  - 가능한 방법 ②: 회사 **카카오톡 채널 + 챗봇**(카카오 i 오픈빌더): 거래처가 회사 채널에 보낸 메시지만 받아 올 수 있음 (채널 개설 · 심사 필요)
  - 인트라넷 → 카톡 알림: '알림톡'은 메시지당 요금이 드는 유료 서비스라 보류 (무료 서비스 원칙). 대신 웹 푸시 · 슬랙 알림 사용
- 결론: 슬랙은 완전 연동, 카카오톡은 '내보내기 파일 가져오기' 로 진행

### 2. 프로젝트별 외부 협업 채팅방 — 가능
- 이미 있는 프로젝트 대화방 · 드라이브 · 일정 위에 **'외부인(게스트)' 역할**을 더함
- 외부인은 초대 링크(만료일 · 1회용)로 가입 → **초대받은 프로젝트 방 하나만** 보임 (다른 프로젝트 · 재무 · 직원 정보는 데이터베이스 권한(RLS)에서 차단)
- 방 안에서: 채팅 · 자료 올리기/받기(드라이브 프로젝트 폴더의 '공유' 폴더) · 공유 일정(마일스톤 · 미팅)
- 외부인 전용 간단 화면 (휴대폰 우선), 초대 · 해제 · 기록은 관리자 화면
- 주의: 보안 점검을 단계마다 함 (외부인 계정으로 내부 자료 접근 시험)

### 3. 협업 화이트보드 — 가능 (오픈소스로 직접 탑재)
- **Excalidraw** (MIT 라이선스 · 무료 · 상업 사용 가능)를 인트라넷 안에 넣고, 저장 · 동시 편집은 우리 Supabase(실시간)로
  - tldraw 는 상업용 라이선스가 유료라 제외, FigJam 은 피그마 계정 · 유료 좌석이 필요해 '바로가기 링크' 정도만 지원
- 프로젝트별 보드 · 도면 · 사진 붙이기 · 포스트잇 · 화살표 · 여러 사람 커서 · PNG/PDF 로 드라이브 저장
- 2번 외부 협업방과 연결해 거래처와 같은 보드를 볼 수 있게
