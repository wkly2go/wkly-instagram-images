# 디자인 v9 — 모노톤 + 네온 빛 (2026-11-28)

대표가 고른 참고 화면 넷(회색 대시보드 둘 · 먹색 그래프 화면 · 파랑 빛 스타일 가이드)을 합친 규칙. 새 화면도 이 규칙대로 만든다.
구현은 `erp/src/mono.css` 한 파일(토큰) — 다른 CSS 에는 색 값을 직접 쓰지 않고 토큰을 쓴다.

## 1. 색
| 쓰임 | 토큰 | 값 |
|---|---|---|
| 바탕 | `--v8-bg` | #f0f0ee |
| 카드 · 입력 | `--v8-card` | #ffffff |
| 선 | `--v8-line` · `--v8-line-2` | #e4e4e1 · #d6d6d2 |
| 제목 · 본문 · 보조 글자 | `--tx-title` · `--tx-body` · `--tx-sub` | #0f0f0f · #1b1b1b · #5e5e5b |
| 고른 것 · 막대 · 먹색 버튼 | `--v8-green`(이름만 예전 것) | #141414 |
| 네온 파랑 | `--v9-accent` · `--v9-accent-tint` | #1f4dff · #e9eeff |
| 정상 · 살아 있음 점 | `--v9-live` | #33d17a |
| 지연 · 경고 | `--red` · 노랑 계열 | 그대로 |

- 색은 회색 계열 하나 + 네온 파랑 하나. 초록 · 보라 · 분홍 · 미색은 쓰지 않는다.
- 바탕은 늘 밝게. 어두운 바탕 화면은 만들지 않는다('화면 어둡게'는 사용자가 고를 때만 · 그대로).
- 구분 색: 아트리어 먹색 · 더위클리 회색 · 공통 연회색(`--div-ar` · `--div-tw` · `--div-rs`).

## 2. 네온 = 빛이 새어 나가는 효과
가장자리에 밝은 테 한 줄 + 오른쪽 아래로 번지는 파랑 빛.
| 단계 | 토큰 | 어디에 |
|---|---|---|
| 약 | `--glow-1` | 주 버튼 기본 · 고른 칩 · 메뉴 고른 줄 · 알림 숫자 |
| 중 | `--glow-2` | 가장 중요한 숫자 카드 · 오늘 · 누를 수 있는 카드에 마우스를 올렸을 때 |
| 강 | `--glow-3` | 주 버튼에 마우스를 올렸을 때 |
| 초점 | `--neon-soft` | 입력 칸 초점 |

- 빛은 '주된 행동 · 고른 것 · 지금(오늘) · 가장 중요한 하나'에만. 한 화면에 여러 곳이 동시에 빛나지 않게.
- 네온 색을 본문 글자색으로 쓰지 않는다(주 버튼 안 흰 글자 · 링크는 먹색 + 밑줄).

## 3. 글꼴
- 영문 · 숫자 **Geist**, 한글 **Pretendard**(`--font`) · 큰 숫자 · 연번 · 날짜 **Geist Mono**(`--mono`) — 모두 무료.
- 크기: 타이틀 18 · 강조 15.5 · 본문 14(터치 18.5 · 16 · 15) 그대로 + 큰 숫자 `--t-num` 24(대시보드 숫자 카드 · 그래프 합계에만).
- 굵기: 타이틀 700 · 강조 600 · 본문 400 (800 · 500 은 쓰지 않음).
- 이름표(`.lbl` · 표 머리): 보조 색 · 자간 .03em · 영문은 대문자.

## 4. 모양
- 모서리: 카드 14 · 버튼 · 입력 10 · 태그 · 배지 알약.
- 높이: 0 = 선만 → 1 = 옅은 그림자(`--v8-shadow`) → 2 = 네온 빛.
- 카드 틀: 회색 머리(제목 · 링크) + 흰 본문(`.dash-card` + `.dash-body`) — 대시보드 · 요약 카드에 쓴다.
- 그래프: 막대 · 점은 먹색 → 회색 단계, 강조 하나만 네온 파랑, 지연만 빨강.
- 상태 알약: 흰 알약 + 왼쪽 빛나는 점(초록 정상 · 빨강 지연).

## 5. 바꿀 때
- 토큰 값은 `mono.css` 맨 위에서만 고친다.
- `main.tsx` 의 `import './mono.css'` 를 빼면 색 토큰이 v8 로 돌아간다(같은 날 CSS 의 굳은 색을 회색으로 바꿨으므로 완전히 예전 초록으로 돌아가지는 않음 — 되돌리려면 git 기록).

## 부드럽게 (2026-11-28 대표 지시 '디자인 ui,ux도 바꿔 · 색상의 사용도 수정하고 · 부드러운 느낌')

- 새까만 색을 쓰지 않는다: 글자 · 막대는 부드러운 먹색 `--v9-ink` #2b2d33, 제목 #1f2126, 보조 #6b6d72.
- 고른 것(칩 · 구간 고르기 · 탭 알약)은 검은 알약이 아니라 연한 파랑 바탕 `--v9-accent-tint` + 먹색 굵은 글자.
- 자주 누르는 버튼(.btn-blue · .btn-yellow)은 연한 파랑 바탕 + 파랑 글자, 올리면 네온 파랑. 가장 중요한 버튼(.btn-primary · 새로 만들기)만 처음부터 네온 파랑.
- 테두리 대신 옅게 번지는 그림자(`--v8-shadow`), 굵은 색 윗선 · 옆선은 쓰지 않는다.
- 모서리: 카드 18 · 버튼 · 입력 12 · 태그 알약. 예전 '모든 모서리 0' 고정(styles.css)은 없앴다.
- 빛(`--glow-1/2/3`)은 딱딱한 테 없이 넓게 번지게. 움직임은 0.2~0.3초로 천천히, 누를 수 있는 카드는 올리면 2px 떠오름, 창 뒤는 뿌옇게.
- 차트 · 화이트보드 · 설계 화면 · 기념일 장식 · PC 오프라인 화면도 회색 + 네온 파랑. 실제 자재 색(3D · 마감재 라이브러리) · 거래처에 나가는 것(제안서 · 메일 · 카드뉴스 · 광고 이미지)은 그대로 둔다.

## 선명하게 · 메뉴마다 다른 색 (2026-11-28 대표 지시 · 참고 'Product UI Styleguide')

- 강조색은 하나가 아니라 **메뉴마다 하나**: `lib/menuColors.ts` MENU_COLORS(메뉴 키 → 색). Shell 이 지금 메뉴의 색을 `--v9-accent` 로 넣고, 빛(`--glow-*`) · 연한 바탕(`--v9-accent-tint`) · 주 버튼은 모두 `color-mix` 로 이 값에서 계산한다. 새 메뉴를 만들면 여기에 색 한 줄(빨강 계열은 지연 · 경고와 헷갈려 쓰지 않음).
- CSS 에 파랑(#1f4dff · rgba(31,77,255,…))을 직접 쓰지 말고 `var(--v9-accent)` · `color-mix(in srgb, var(--v9-accent) N%, transparent)` 를 쓴다. 달력 '내 업무'(`--cal-mine`)만 늘 파랑.
- 왼쪽 메뉴 아이콘은 그 메뉴 색의 작은 칸 안에(고른 줄은 색을 채운 칸 + 흰 아이콘).
- 카드는 흰 바탕 + 또렷한 1px 선(`--v8-line` #dbdbd7) + 옅은 그림자, 바탕은 #eeeeeb — 카드끼리 경계가 분명해야 한다.
- 구간 고르기(광고 조회 기간 등)는 둥근 홈 안의 알약: 고른 칸은 메뉴 색 + 흰 글자. 묶음 탭은 홈 안의 흰 카드.

## 볼록 · 오목 (2026-11-28 대표가 참고 그림 두 장으로 고름 — 뉴모피즘)

- 면은 바탕과 거의 같은 밝은 회색(`--nm-bg` · `--nm-face`), 구분은 선이 아니라 **왼쪽 위 밝은 빛 + 오른쪽 아래 그림자**.
- 떠 있는 것 `--nm-up` / `--nm-up-sm`: 카드 · 버튼 · 고른 탭 알약. 눌린 것 `--nm-in` / `--nm-in-sm`: 입력 칸 · 구간 고르기 홈 · 고른 칩 · 고른 메뉴 줄 · 누르는 순간.
- 구간 고르기(.ads-segment · .seg · .right-tabs)는 회색 홈 + 흰 알약(고른 것).
- 켜고 끄는 설정은 `<input type="checkbox" className="nm-switch">`(켜면 먹색 홈 + 흰 손잡이). 여러 개를 고르는 목록 · 할 일 완료 칸은 네모 체크 그대로.
- 색은 메뉴 색(`--v9-accent`)을 작은 곳(아이콘 칸 · 주 버튼 · 고른 글자 · 오늘)에만.

## 나머지 화면 · 각진 모서리 (2026-11-28 대표 지시)

- 흰 바탕은 쓰지 않는다: `--white` · `--v8-card` 와 CSS 의 흰 바탕(`background: #fff` 등)은 모두 `var(--nm-face)`. 새 CSS 도 바탕은 `var(--nm-face)`.
- 테두리 있는 묶음 칸은 떠 있는 모양(`--nm-up-sm`) — mono.css 맨 아래 목록에 클래스를 더한다.
- 모서리: 카드 10 · 버튼 · 입력 7 · 칩 · 태그 7 · 큰 판(본문 · 메뉴) 12. 알약(999px) · 원은 스위치와 숫자 동그라미에만.

- (2026-11-28 대표 '이거는 모노톤으로') **왼쪽 메뉴는 모노톤**: 아이콘 · 고른 줄 · 숫자 칸 · '새로 만들기'는 먹색 · 회색만. 메뉴 색은 그 화면 안(주 버튼 · 고른 것 · 그래프)에서만 쓴다.

## 최종 규칙: 모노톤 + 네온 그림자 (2026-11-28 대표 '너무 많은 색을 사용하지마 · 전체적으로 모노톤에 그림자를 네온 번지는 효과로 · 각 메뉴마다 다른 색' — 위의 앞선 규칙과 다르면 이 절이 우선)

- 면 · 글자 · 아이콘 · 버튼 · 숫자 동그라미 · 그래프 막대는 **먹색과 회색만**. 색 글자 · 색 바탕 버튼 · 색 배지를 만들지 않는다. 빨강(산호색)은 지연 · 경고에만.
- 메뉴 색(`--v9-accent` · `lib/menuColors.ts`)은 **그림자가 번지는 빛**으로만: `--nm-neon-sm`(주 버튼 · 고른 것 · 오늘) · `--nm-neon`(가장 중요한 카드 · 올린 카드 · 본문 판 아래).
- 주 버튼 = 먹색 바탕 + 흰 글자 + 네온 그림자. 고른 칩 = 눌린 홈 + 먹색 굵은 글자 + 네온 그림자.
- 휴대폰도 같은 규칙: 아래 메뉴는 떠 있는 판, 고른 칸은 눌린 홈 + 네온 그림자, 본문은 판 없이 바탕 위에 카드.
