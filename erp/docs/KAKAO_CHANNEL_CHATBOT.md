# 카카오톡 채널 챗봇 검토 (로드맵 1-4 · 2026-11-17)

> 1단계 '슬랙 · 카카오톡 연결' 마지막 검토. 결론부터: **지금은 만들지 않고 보류**, 대신 2단계 외부 협업방의 초대 링크를 카톡으로 보내는 방식을 권장.

## 1. 챗봇으로 되는 것 · 안 되는 것

| 질문 | 답 |
| --- | --- |
| 거래처와 하는 **단톡방 · 개인 톡**을 읽어 올 수 있나 | **안 됨.** 카카오가 개인 · 단체 대화방을 읽는 API 를 주지 않음. 지금처럼 '대화 내보내기' 파일 올리기(1-3)가 유일한 방법 |
| 거래처가 **회사 카카오톡 채널**에 보낸 1:1 메시지를 받을 수 있나 | 됨. 오픈빌더 챗봇의 '스킬 서버'로 우리 서버(Supabase 함수)가 받아 저장 · 답장 |
| 받은 메시지를 프로젝트 대화에 넣을 수 있나 | 가능하지만 **누가 어느 프로젝트인지 맞추는 단계**가 따로 필요 (채널 사용자 키 ↔ 거래처 연결 코드) |
| 인트라넷에서 거래처에게 **먼저** 카톡을 보낼 수 있나 | 이벤트 API 로 가능하지만 **유료 (건당 15원 · VAT 별도, 개발 채널도 과금)** → 무료 원칙에 맞지 않음 |
| 응답 시간 | 스킬 서버는 **5초 안에** 답해야 함. 넘으면 콜백(1회용 주소)으로 나중에 답 |

## 2. 준비해야 하는 것

1. 회사 카카오톡 채널 (지금 저장소 · 홈페이지에서 회사 채널은 찾지 못함 → 대표 확인 필요)
2. 채널 관리자센터에서 **비즈니스 채널 인증** (사업자등록번호 · 심사)
3. 카카오 디벨로퍼스 **비즈 앱 인증**(사업자 기준) + 앱의 '카카오 로그인 활성화' + 채널과 앱 연결
4. 카카오 i 오픈빌더에서 봇 만들기 → 스킬(우리 서버 주소) 연결 → 배포 → 운영 채널 연결
5. 우리 쪽: 스킬 수신 함수(공개 주소 · 카카오 요청만 받도록 확인) · 메시지 표 · 거래처 연결 코드 화면 · 개인정보 안내

1~4는 대표 계정 · 사업자 서류가 필요하고 카카오 심사 기간이 있음.

## 3. 판단

- 우리 협업 상대(브랜드 · 대행사 · 협력사)는 대부분 **단톡방**으로 일함 → 챗봇은 이 대화를 가져오지 못해 효과가 작음.
- 회사 채널 1:1 메시지는 **새 문의 접수**(영업)에는 쓸모가 있으나, 그건 영업 담당 구역이고 지금 목표(프로젝트 협업 기록)와 다름.
- 2단계 외부 협업방은 **초대 링크**를 카톡으로 보내기만 하면 됨 (무료 · 심사 없음 · 자료 · 일정까지 공유).

**권장:** 챗봇은 보류. 프로젝트 협업은 ① 단톡방은 '대화 내보내기' 올리기(1-3) ② 앞으로의 협업은 2단계 외부 협업방 링크를 카톡으로 공유.
나중에 회사 채널을 만들어 문의 접수를 자동화할 때 이 문서의 2번 순서로 다시 시작.

## 4. 대표님께 여쭐 것 (11/18 1단계 점검)

1. 회사 카카오톡 채널이 있는지 (있다면 채널 주소)
2. 챗봇 보류 · 외부 협업방 링크 공유로 가는 것에 동의하시는지
3. 1-3 카카오톡 '대화 내보내기' 파일을 실제 단톡방 하나로 시험해 주실 수 있는지 (휴대폰 › 채팅방 › 설정 › 대화 내용 내보내기 → 프로젝트 화면 '카카오톡 대화'에 올리기)
