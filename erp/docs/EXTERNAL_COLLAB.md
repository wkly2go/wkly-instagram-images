# 외부 협업방 (로드맵 2단계 · 2026-11-17 설계)

거래처(발주처) · 협력사가 **로그인 없이 초대 링크로** 들어와, 초대받은 **방 하나만** 보고
대화 · 자료 · 일정을 함께 쓰는 화면. 대표 지시 '이 순서대로 개발 시작해'(2026-11-17) 4번.

## 1. 무엇을 하나

| 쪽 | 할 수 있는 일 |
| --- | --- |
| 팀원 (프로젝트 화면 › 외부 협업방) | 방 만들기(프로젝트마다 여러 개 · 예: 발주처방 / 시공 협력사방) · 외부인 초대 · 링크 다시 만들기 · 접속 해제 · 대화 · 자료 올리기/받기 · 공유 일정(미팅 · 마일스톤) 관리 · 방 닫기 |
| 외부인 (`/c/<초대 링크>` · 휴대폰 우선) | 초대받은 방의 대화 읽기/쓰기 · 자료 받기 · 자료 올리기(팀원이 막을 수 있음) · 공유 일정 보기 |

- 자료는 **드라이브 프로젝트 폴더 › 01.협의자료 › 03.외부공유** 에 둔다. 팀원이 드라이브에서 그 폴더에 직접 넣어도 외부인에게 보인다.
  외부인이 올린 파일도 같은 폴더로 들어간다(기존 드라이브 파일은 고치거나 지우지 않음 · 새 폴더 · 새 파일만).
- 방을 나누는 이유: 발주처와 협력사가 한 방에 있으면 단가 · 공정 이야기가 서로에게 보일 수 있음. **한 방 = 같은 내용을 봐도 되는 사람들.**

## 2. 권한 (보안) 설계

외부인은 Supabase 계정을 만들지 않는다. (회원 가입은 꺼져 있고 · `handle_new_user` 를 거치지 않으며 · 팀원 목록(`profiles`)에 섞이지 않음)

1. **초대 링크 = 1회용**: 팀원이 초대하면 서버가 32바이트 난수로 링크를 만들고 DB에는 **해시(SHA-256)만** 저장. 링크는 화면에 한 번만 보임.
   링크를 처음 연 기기가 **기기 열쇠**(32바이트 난수 · 해시만 저장)를 받고 링크는 그 자리에서 쓸모없어짐 → 링크가 전달 · 유출돼도 다른 기기에서는 안 열림.
   같은 기기(같은 브라우저 · 카카오톡 안 브라우저 포함)에서 다시 열면 저장된 열쇠로 바로 들어감. 다른 기기는 팀원이 '링크 다시 만들기'.
2. **만료 · 해제**: 외부인마다 만료일(기본 60일) · 초대 링크는 14일 안에 열어야 함. '접속 해제'를 누르면 그 사람의 모든 기기가 즉시 막힘. 방을 닫아도 막힘.
3. **DB 직접 접근 없음**: 외부인은 PostgREST(테이블 · RPC)에 아무 권한이 없다(`anon` 권한 없음). 모든 요청은 서버 함수 `collab` 하나로만 들어오고,
   함수가 기기 열쇠 → 외부인 → 방을 확인한 뒤 **그 방 id 로만** 읽고 쓴다(요청에 담긴 방 id 를 믿지 않음).
4. **기기 열쇠 표**(`collab_links`)는 팀원도 못 읽음(RLS 켜고 정책 없음 · 권한 회수). 서버 함수(service role)만.
5. **팀원 쪽**: 방 · 외부인 · 대화 · 일정 · 파일 기록은 활성 팀원(`is_active_member()`)만 읽고 쓴다. 팀원 대화는 본인 이름으로만(`user_id = auth.uid()`).
6. **파일 받기**: 함수가 그 파일이 방 폴더(하위 2단계까지) 안에 있는지 확인한 뒤 5분짜리 서명 표(HMAC)를 주고, 그 표로만 받는다. 드라이브 공유 설정은 바꾸지 않는다.
7. **파일 올리기**: 방 폴더에만 · 파일당 100MB · 함수가 만든 구글 이어 올리기 주소로 브라우저가 바로 올림(서버 용량 · 요금 없음). 올린 뒤 함수가 그 파일이 방 폴더 안인지 다시 확인하고 기록.
8. **도배 막기**: 외부인 글은 4,000자 · 1분에 20개까지. 팀원 알림은 같은 제목이면 하루 한 번만 새로 뜸(기존 알림 합치기).
9. 외부인에게 보이는 팀원 정보는 **이름 · 직함 · 회사(아트리어/더위클리)** 뿐. 메일 · 전화 · 사진 · 재무 · 다른 프로젝트는 보내지 않는다.

## 3. 데이터

| 표 | 내용 | 누가 |
| --- | --- | --- |
| `collab_rooms` | 프로젝트 · 방 이름 · 첫 화면 안내 · 드라이브 폴더 · 닫힘 | 팀원 RLS · 함수 |
| `collab_guests` | 이름 · 회사 · 역할(발주처/협력사/기타) · 올리기 허용 · 만료 · 해제 · 마지막 접속 · 읽은 시각 | 팀원 RLS(만들기는 함수) · 함수 |
| `collab_links` | 초대 링크 해시 · 기기 열쇠 해시 · 기기 이름 · 사용 · 해제 | **함수만** |
| `collab_messages` | 대화 (팀원 user_id 또는 외부인 guest_id) · 첨부 파일 목록 · 지움 | 팀원 RLS · 함수 · 실시간(팀원) |
| `collab_events` | 공유 일정: 미팅 · 마일스톤 · 일정 (날짜 · 끝 날짜 · 시각 · 장소 · 메모) | 팀원 RLS · 외부인은 읽기(함수) |
| `collab_files` | 인트라넷으로 올린 파일 기록(누가 올렸는지) | 팀원 RLS · 함수 |

## 4. 화면

- 팀원: 프로젝트 화면 '외부 협업방' 칸 — 방 고르기 · 외부인 줄(접속 상태) · 대화 · 자료 · 공유 일정 · 초대 창(링크 복사 + 카카오톡으로 보낼 안내 문구 복사).
  **링크는 팀원이 직접 카카오톡 · 메일로 보낸다**(인트라넷이 외부로 메일 · 메시지를 보내지 않음).
- 외부인: `/c/<링크>` — 회사 이름 · 방 이름 · [대화 | 자료 | 일정] 세 칸 · 아래 입력줄(파일 첨부) · 밝은 화면 · 휴대폰 우선.
  새 글은 화면을 보고 있는 동안 8초마다 확인(화면을 내리면 멈춤).

## 5. 알림

- 외부인이 글 · 파일을 올리면 프로젝트 담당 · 참여 팀원 · 방을 만든 사람 · 초대한 사람에게 알림(종 · 휴대폰 푸시).
- 외부인에게 가는 알림은 1차에 없음(메일 · 알림톡은 외부 발송 · 유료라 보류). 2-4 에서 무료 웹 푸시(외부인이 '알림 받기'를 누른 경우만)를 검토.
