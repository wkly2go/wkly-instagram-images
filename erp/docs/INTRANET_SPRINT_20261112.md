## 현재 후속 개발·검증 범위

- 회의록은 기존 상태·시각과 고유 표식으로 한 요청만 시작하고 완료 ID·불확실 요청을 자동 재실행하지 않습니다. 최종 저장 응답 유실은 같은 완료 내용을 재조회해 확인하며 검토가 필요한 결과는 원본 ID를 유지합니다. 원본 읽기·정리 전에 작성자 소유 경로를 확인합니다.
- 회의록 접수 응답은 30초, 상태 조회는 독립적인 20분 제한을 둡니다. 결과 불확실 시 새 업로드를 막고 같은 ID의 상태만 재조회합니다. 정상 결과 저장이 확인된 작업 뒤에만 정리를 실행합니다. 삭제 후보는 현재 완료 상태이고 생성일 기준 30일 지난 기록이며 실패·업로드·처리 중 원본은 보존합니다.
- 연락처는 제목·이메일·인스타 계정·브랜드·담당자, 공고는 제목·공고번호·발주처로 검색합니다. 특수문자를 검색 문법으로 실행하지 않고 문자 그대로 찾으며 체험·실제 조회 조건을 맞춥니다.
- 나라장터 공식 조회는 버튼으로 후보를 가져와 원문과 조건을 검토한 뒤 저장하는 흐름입니다. 자동 저장·예약 수집·투찰은 하지 않습니다. 공식 응답 계약·활용 승인·서버 배포·운영 API 검증 완료 전에는 직접 등록을 사용합니다.
- Gmail은 기간·페이지·남은 ID를 보존해 상한이나 실패 때문에 메일을 건너뛰지 않도록 보완했습니다. 최근 메일 새로고침과 과거 가져오기 진행을 분리하고 저장을 확인한 뒤에만 다음 페이지로 이동합니다. 생성기·단일 배포물은 준비됐고 실제 계정 동기화·서버 배포는 미확인입니다. [Gmail 배포 안내](GMAIL_SYNC_DEPLOYMENT.md)를 따르며 웹 배포와 구분합니다.
- Google 로그인은 자동 승인 검토에서 명시적 승인 확인 불가로 차단되어 운영 계정에 접속하지 않았습니다. 이를 실제 Gmail 동기화·RLS 확인 완료로 보고하지 않습니다.

## 구현 범위

- 영업: 거래처·담당자·단계·다음 행동·연락일·활동 기록·같은 회사/거래처 프로젝트 연결. 예상 금액과 확정 매출 분리.
- 공고: 번호+차수 중복 방지, 원문·발주처·금액·한국시간 마감, 참가 조건과 근거, 영업 연결 재시도 중복 방지.
- 콘텐츠: 원본 사실과 네이버 블로그/인스타그램/유튜브 버전. 저장 후 관리자 승인, 내용 변경 시 승인 해제, 실제 발행 URL 기록, 동일 회사의 기존 광고 캠페인 연결.

- 인스타그램: 보관한 내보내기 텍스트에서 계정 후보 미리보기·선택 제외·최대 50개 저장. 계정 자동 수집 완료로 표시하지 않음.
- 조회: 30건 페이지·목록 본문 제외·상세 선택 조회·검색 350ms 지연. 기존 전송량 절감 기능 유지.
- 권한: 담당자/관리자 수정, 관리자 재배정·콘텐츠 승인·AI 예산 설정, 동시 수정 버전 검사, 감사 이력.
- AI: 버튼으로 요청할 때만 API 호출. 서버 키, 6,000자 입력·1,600 출력 토큰·요청당 예약 $1 상한·기간 배정액 제한. 동일 요청 ID 중복 차단. 불확실 응답은 예약 유지 후 관리자가 실제 비용과 근거를 기록. 자동 충전·자동 기간 갱신 없음.
- 기본 업무는 AI 없이 가능. 요청문 복사·수동 작성 대체 경로 제공. AI 비용 집계는 이 도구 호출만 포함하며 다른 API 키·기존 AI 팀원·Max 잔액과 구분.

## 검증과 제한

- 이번 후속 회귀는 291/291, 실제 React 컴포넌트 jsdom 검사는 별도 14/14로 합계 305/305입니다. 기존 PR #367의 208개에 서버·검색·화면 안전성 검사를 추가했습니다. TypeScript·프로덕션 빌드와 배포본 3개 원본 일치 검사도 통과했습니다. 모의 응답과 로컬 PGlite를 사용했으며 실제 Gmail·나라장터·Claude 호출은 없습니다.
