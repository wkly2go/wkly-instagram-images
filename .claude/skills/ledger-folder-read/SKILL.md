# 회계 자료 폴더 전체 읽기 (대표 지시 2026-11-12)

인트라넷과 같은 읽는 법을 쓴다: `erp/src/lib/ledgerImport.ts` (은행 · 카드 · 세금계산서 판별과 분류), `erp/src/lib/folderScan.ts` (하위 폴더 끝까지 · zip 풀기 · 파일 종류 · 개인 자료 거르기).

## 꼭 지킬 것
- **개인 자료는 열지 않는다.** 이름에 연말정산 · 근로계약 · 주민등록 · 원천징수영수증 · 급여명세 등이 들어간 폴더나 파일(`PRIVATE_RE`). 주민번호 저장 금지.
- 드라이브 파일은 **고치거나 지우지 않는다** (읽기만).
- 장부(운영 DB)에 넣을 때는 인트라넷 '회계 자료' 탭을 쓰는 것이 기본이다. DB 에 직접 넣거나 고칠 때는 대표에게 무엇을 바꾸는지 먼저 알린다.
- 대표에게는 한국어 존댓말로 보고한다.

## 1. 인트라넷에서 (가장 쉬움)
입출금 장부 › '회계 자료' 탭
- **폴더 전체 점검** 버튼: 연결된 드라이브 폴더를 하위 폴더 끝까지 훑어, 파일마다 '읽음 · N줄 / 아직 안 읽음 / 거래 내역 아님 / PDF · 이미지라 넣지 않음 / 개인 자료라 열지 않음'을 표로 보여 준다. '아직 안 읽은 N개 지금 읽기'로 바로 기입.
- 장부를 열 때 자동 읽기도 하위 폴더 끝까지 본다(최대 8단계). zip 은 풀어서 안의 엑셀 · CSV 를 따로 기입한다.
- **폴더 전체 올리기**: PC 폴더를 통째로 고르면 하위 폴더 · zip 까지 읽는다.

## 2. Claude 세션에서 드라이브 폴더 점검
1. 회계 자료 폴더 id: `select value from public.cash_ledger_meta where key='folder'` (`root`).
2. 하위 폴더 끝까지 목록: Google Drive `search_files` 로 `parentId = '<id>'` 를 폴더마다 반복 (여러 폴더는 `or` 로 묶기, `excludeContentSnippets: true`, `pageSize: 200`). 결과가 크면 도구 결과 파일로 저장되므로 python 으로 읽는다.
3. 처리 기록과 맞춰 보기: `select drive_file_id, name, kind, rows, added, note from public.cash_ledger_files` — 목록에 없는 엑셀 · CSV · zip 이 '아직 안 읽음'.
4. 내용 보기
   - 엑셀(.xlsx) · PDF · 구글 시트: `read_file_content` 로 글자만 빠르게 볼 수 있다 (`.xls` 는 안 됨).
   - 정확히 읽으려면 `download_file_content` → base64 를 풀어 파일로 저장 → 아래 3번 스크립트. (결과가 크면 도구가 파일로 저장해 준다. 작은 파일은 대화에 바로 나오므로, 그때는 `read_file_content` 글자를 쓰거나 대표에게 인트라넷 '폴더 전체 점검'을 안내한다.)

## 3. 받아 둔 로컬 폴더를 한 번에 읽기
```bash
cd <저장소> && (cd erp && npm ci)   # 처음 한 번
npx --prefix erp tsx .claude/skills/ledger-folder-read/read-folder.mts <폴더> [--json 결과.json]
```
파일마다 경로 · 종류(은행/카드/세금계산서/거래 내역 아님/PDF…) · 줄 수 · 기간 · 출금/입금 합계 · 통장 이름을 보여 주고, 끝에 건수를 요약한다. 장부에는 넣지 않는다.

## 4. 보고 형식 (대표에게)
1. 장부에 넣어야 하는데 아직 못 읽은 거래 자료 — 경로 · 파일 · 내용
2. 열어 봤지만 거래 내역이 아닌 표 (잔액 확인표 · 매입장 · 요약표)
3. PDF · 이미지 (세금계산서 PDF 는 홈택스 목록 엑셀로 대신)
4. 열지 않은 개인 자료 · 압축 · 프로그램
그리고 다음에 할 일(올릴 자료 · 고칠 것)을 한두 줄로.

## 읽는 법을 바꿀 때
`erp/src/lib/ledgerImport.ts` · `folderScan.ts` 를 고치고, `LedgerFolder.tsx` 의 `READER_VERSION` 날짜를 올리면 예전에 못 읽은 파일을 다음 장부 열기 때 다시 시도한다.
